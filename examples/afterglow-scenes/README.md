# Afterglow Scene Starter

Two editable scenes demonstrate theme-following ring outlines, seeded particles and moving polygon layers. See [the format reference](../../afterglow-scenes.md).

Edit `content/lyrics-style.json`, run SDK `sync` and `validate`, then ZIP the contents of `content`. Import the ZIP from the Afterglow look gallery, or use the existing Workshop publishing workflow with the `Lyrics Scene` tag. A `preview.png` should be provided before publishing. The bundled manifest is for this exact sample; after editing, regenerate its size and SHA-256 inventory.
